每轮两个相邻整分钟时段（end 为末分钟的下一分钟，左闭右开），版本必须分别为 old / new；各轮时段互不重叠。也可用 POST /api/schedule。

② 上传 / 补传某一分钟日志

字段说明

每条含 txn_id 办理号、ts 时间、type（start / success）。每个办理号仅允许一次开始；同一分钟重复上传会整分钟替换，并只重算观测窗口覆盖该分钟的轮次。也可用 POST /api/logs/minute。

③ 迁入历史轮次（一轮排班 + 该轮观测窗口内的分钟包）

规则说明

文件含一轮原格式排班（round）与该轮观测窗口内的原格式分钟包（minutes）。 库中没有的包补入，已有的包照用；两边都有同一分钟时，事件内容与重复条数必须一致（顺序不限），有差异即列出冲突分钟并拒绝迁入。 沿用排班、轮次号唯一、办理开始全局唯一校验。预览列出待补分钟、新轮结果，以及受补入影响的已有轮次迁入前后的纳入状态与成功率差； 确认时按当前库重新核对，补入清单、受影响轮次或预览结果有变需重新预览，无关补传不妨碍确认。 JSON 接口：POST /api/migration/preview 与 POST /api/migration/confirm。
