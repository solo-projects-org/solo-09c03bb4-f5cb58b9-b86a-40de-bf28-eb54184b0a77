# 自助缴费机提示版本轮换 · 两版办理成功率对比

运营员比较同一轮里新旧两版提示的办理成功率。FastAPI + SQLite，Docker Compose 启动。

## 业务规则（实现口径）

1. **固定排班**：每轮两个相邻、提示版本不同（`old` / `new`）的整分钟时段（左闭右开），各轮排班时段互不重叠。排班只允许导入一次，重复导入返回 409。
2. **分钟日志**：按整分钟上传，`entries` 为该分钟全部日志；补传 = 整分钟替换；空包 `entries: []` 同样算作该分钟已收齐。每条日志含办理号 `txn_id`、时间 `ts`、类型（`start` / `success`）。每个办理号全局只允许一次开始，违反则整包拒绝。
3. **归组**：按**开始事件所在时段的版本**归组（跨时段缴费仍算开始版本的办理）。开始后 **10 分钟内（含恰好 10 分钟边界）**出现成功即计为成功；同一办理号多次成功只计一次。
4. **纳入条件（两者同时满足）**：
   - 观测窗口 = 首段开头 → 末段结束后 10 分钟（左闭右开）内**每个整分钟**都收到日志包（空包也算）；
   - 新旧两版都至少有一个开始。
   不满足的轮次在网页列出并注明原因（缺哪些分钟 / 哪一版无人开始），不参与平均。
5. **差值与平均**：纳入轮次输出 `新版成功率 − 旧版成功率`（百分点 pp），页面顶部给出这些差值的**算术平均**。
6. **增量重算**：上传/补正某分钟时，只重算观测窗口覆盖该分钟的轮次；日志替换与统计更新在同一个 SQLite 事务内提交。
7. **失败安全**：解析、校验或重算失败时事务回滚，原日志与原统计保持不变（HTTP 400/409/422）。

## 启动（Docker Compose）

```bash
docker compose up --build
# 打开 http://localhost:8000
```

SQLite 数据保存在命名卷 `kiosk-data`（容器内 `/data/app.db`）。
清空全部数据可调用 `POST /api/reset`（演示用）。

## 页面与接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 网页：汇总平均、各轮状态/成功率/差值/未纳入原因、排班与日志上传表单 |
| POST | `/schedule` | 网页表单导入排班 |
| POST | `/logs` | 网页表单上传/补传分钟日志 |
| POST | `/api/schedule` | JSON 导入排班（201；重复导入 409） |
| POST | `/api/logs/minute` | JSON 上传/补传整分钟日志，返回受影响并重算的轮次 |
| GET | `/api/rounds` | 全部轮次统计与平均差值（JSON） |
| GET | `/api/minutes` | 已收齐的分钟包清单（JSON） |
| POST | `/api/reset` | 清空排班、日志与统计（演示用） |

排班 JSON 示例见 `sample/schedule.json`：

```json
{
  "rounds": [{
    "round_id": "R1",
    "segments": [
      {"version": "old", "start": "2026-11-20T09:00", "end": "2026-11-20T09:01"},
      {"version": "new", "start": "2026-11-20T09:01", "end": "2026-11-20T09:02"}
    ]
  }]
}
```

分钟日志包示例：

```json
{
  "minute": "2026-11-20T09:00",
  "entries": [
    {"txn_id": "T1", "ts": "2026-11-20T09:00:20", "type": "start"},
    {"txn_id": "T1", "ts": "2026-11-20T09:09:55", "type": "success"}
  ]
}
```

## 本地试跑（无 Docker 环境时）

```bash
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
python3 tests/e2e_test.py            # 对运行中的服务打真实 HTTP 请求，30 项断言
```

`tests/e2e_test.py` 覆盖：排班校验（非整分钟、不相邻、重复导入）、跨时段缴费归组、
10 分钟边界与超时、空包收齐、缺分钟未纳入、某一版无人开始未纳入、算术平均、
分钟补正（整分钟替换 + 仅重算覆盖轮次，含窗口重叠的相邻轮次联动）、
坏包/重复开始/错分钟被拒且原数据不变、网页 HTML 渲染。

## 说明与限制

- 所有时间均为**无时区本地时间**，分钟键采用「日历序日 × 1440 + 当日分钟」编码，
  不经过任何时区换算，避免容器/宿主时区差异。
- 观测窗口可能重叠的相邻轮次共享同一分钟包；补传该分钟会联动重算所有覆盖它的轮次（测试已覆盖）。
- 开始事件若落在观测窗口的 10 分钟尾巴（不属于任何时段）会被忽略，不归入任何版本。
